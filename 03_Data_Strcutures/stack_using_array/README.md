# Stack Implementation Using Array

## Overview

This project implements a **Stack data structure using an array in C**.

A stack follows the **LIFO (Last In First Out)** principle, which means the element inserted last is removed first.

## Operations Implemented

### 1. Push

Adds an element to the top of the stack.

### 2. Pop

Removes and returns the top element from the stack.

### 3. Peek / Top

Returns the top element without removing it.

### 4. isEmpty

Checks whether the stack contains any elements.

### 5. isFull

Checks whether the stack has reached its maximum capacity.

## Implementation Details

- Language: C
- Data Structure: Array
- Memory Allocation: Static Array
- Access Method: Index based access
